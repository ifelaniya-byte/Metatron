# self/ — Metatron's own self-model (it may edit these)

These two files are Metatron's **writable self-model** — the second copy of
its own identity that it owns and revises as it learns:

- `IDENTITY_SELF.md` — its self-editable copy of `SELF_IDENTITY.md`. The
  prose charter core stays as the anchor; the marked blocks
  (`CURRENT_FORM`, `PROVEN_ABILITIES`, `ACTIVE_FRONTIER`) are regenerated by
  the editor.
- `JOURNAL.md` — append-only evidence log in Metatron's own words.

The anchored charters `SELF_IDENTITY.md` and `LEARNING_MISSION.md` (in the
repo root) are **not** writable through this mechanism; the editor refuses
to touch them. That keeps a stable identity while letting the working
self-model grow.

## The rule

Metatron may update its self-model **only** through
`daycare/self_editor.py`, and an ability enters the self-model solely with
a measured metric and a reproduction command:

```bash
# Sync current form from the daycare ledger
python daycare/self_editor.py sync

# Register a PROVEN ability (refused without --metric and --reproduce)
python daycare/self_editor.py note \
  --ability digit-addition \
  --metric "held-out digit addition acc 0.96 (n=31)" \
  --reproduce "python daycare/math_literacy.py" \
  --body "I answer held-out addition facts correctly."

# Log an observation / failure (recorded, but registered as no ability)
python daycare/self_editor.py note --observation \
  --metric "identity facts x+0=x acc 0/6" \
  --reproduce "python daycare/math_literacy.py" \
  --body "I learn answer frequency before operand conditioning."

# Update the active frontier (must carry a measured anchor)
python daycare/self_editor.py frontier \
  --statement "Drilling identity/copy facts first, then the addition table." \
  --metric "digit arithmetic held-out acc 0.17"
```

An ability claim with no metric, or no way to reproduce it, is refused.
Failure is logged as observation, never as a claimed skill. This is the
file-level form of the charter: *truth over praise, the gate is sacred.*

Tests: `tests/test_self_editor.py`.
